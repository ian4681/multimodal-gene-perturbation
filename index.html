1Scientific Question

Given a cancer cell line, a perturbed gene (e.g., TP53 knocked out), and a target gene, predict whether the target gene is Up-regulated, Down-regulated, or Non-differential in the post-perturbation transcriptome.

Data: PerturbQA from the AROMA benchmark — pooled single-cell CRISPR screens (Perturb-seq) on K562 (leukemia), HepG2 (liver cancer), Jurkat (T-cell leukemia), and RPE1 (retinal epithelium) cell lines. Label encoding: 0 = Non-diff, 1 = Down, 2 = Up. Class imbalance: ~87% / 4% / 9%.

3Feature Engineering

🔗

BFS Path Features

5 dimensions · from STRING gene interaction graph

For each (perturbed gene, target gene) pair, we run single-source BFS from the perturbed gene on the STRING-derived PPI graph (18,479 nodes) with cutoff=6. Grouping by unique perturbed gene reduces BFS calls from 157k to ~hundreds.

path_length is_direct_neighbor n_common_neighbors degree_pert degree_gene
🧬

ESM-2 Protein Embeddings

640 dimensions · ESM-2 8M, frozen

We pre-compute 320-dim mean-pooled embeddings for all 18,479 graph genes using ESM-2 8M (facebook/esm2_t6_8M_UR50D), running on CPU with batch_size=32. Each (pert, target) pair contributes one embedding per gene → 640 dims total. 98.7% coverage (234 genes missing in UniProt, zero-filled).

esm_pert_0..319 esm_gene_0..319

GO Term Overlap

4 dimensions · Gene Ontology annotations

For each gene pair, we count the number of shared GO terms across three namespaces: Biological Process (BP), Molecular Function (MF), and Cellular Component (CC). Parsed from goa_human.gaf using goatools. NOT-qualified annotations are excluded.

Graph Attention Network (2-layer GAT)

As an alternative to the Random Forest baseline, we train a Graph Attention Network directly on the PPI graph to learn context-aware gene representations. Each node's initial feature is its ESM-2 320-dim embedding; pair-level GO features are appended after graph encoding.

ARCHITECTURE

# Node features: ESM-2 320-dim GAT-1: 320 → 128 (4 heads × 32) GAT-2: 128 → 64 (1 head) MLP: concat(pert[64], gene[64], GO[4]) → 128 → 64 → 3 classes Dropout: 0.3 | LR: 1e-3 | WD: 1e-4

Analysis: The GAT model achieves significantly better recall on the minority Down class (47% vs 18%), suggesting that graph-level neighborhood information helps identify directly regulated downstream targets. However, overall accuracy drops 21 percentage points, likely due to the difficulty of training a graph neural network on a severely imbalanced classification task with CPU-only compute. The RF's lower Down recall reflects its reliance on static, pre-extracted features rather than learned representations.

5Discussion & Future Directions

🧠

ESM-2 Dominates

Protein sequence embeddings explain almost all model performance. Network topology (BFS) and functional annotation (GO) contribute negligible additional signal, pointing to sequence-encoded regulatory constraints as the key determinant of perturbation direction.

📊

Cell-Line Context Gap

Cross-cell-line F1 drops 0.07–0.11 — the model lacks cell-type-specific transcriptional context. The fix: augment features with baseline expression profiles (DepMap CCLE PCA embeddings, ~50 dims) to condition predictions on cell state.

🏗️

GNN Tradeoff

The 2-layer GAT sacrifices global accuracy for minority-class recall. A hybrid approach — RF for common cases, GNN for rare Down predictions — could combine both strengths. Alternatively, fine-tuning a larger ESM-2 variant on perturbation data.

🔬

Clinical Validation

Model predictions can be biologically validated using TCGA patient cohorts: genes predicted as "Down" targets of driver LOF mutations should show systematically lower expression in patients harboring those mutations (Mann-Whitney + FDR correction).
